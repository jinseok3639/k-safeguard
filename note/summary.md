# k-safeguard — 작업 노트

한국어 음운·표기 난독화에 대한 가드레일 robustness를 측정하고, **재학습 없이 가드레일 앞단에 붙는 정규화/복원 게이트웨이**로 방어력을 복원하는 오픈소스. 팀 온돌 · 2026 OSS 개발대회 자유과제(보안·안전).

> 판정: **GO-PENDING**. 실행·측정·ROI·스코프는 통과. 유일한 미결 = 핵심 전제("음운 난독화가 현대 LLM 가드레일을 실제로 뚫는가")의 대규모 실증. 시드 확장으로 재현되면 GO.
> Git 워크플로·커밋 규칙은 `.claude/CLAUDE.md` 참조.

---

## 1. 컨셉

**무엇** — 된소리·연음처럼 발음을 반영한 한국어 표기 변형이 가드레일을 얼마나 우회하는지 정량 측정하고, 그 변형을 표준 표기로 복원하는 전처리 게이트웨이를 만든다. 게이트웨이는 **판단하지 않고 복원만** 한다 — 최종 통과/차단은 항상 하위 가드레일이 맡는다(그래서 범주 무관하게 뒷단이 커버하는 모든 걸 같이 커버).

**왜 이 문제** —
- 음운 변형은 인코딩 트릭이 아니라 **정상 바이트**다. "까"는 "가"의 호모글리프가 아니고 "머글게"는 정당한 표기라, **NFKC/유니코드 정규화가 손댈 대상이 없다.** 기존 정규화 레이어를 그대로 통과한다.
- 순수 대화형 챗봇은 도구·환경 제한(하네스)이 불가능해 **콘텐츠 분류기가 유일한 실질 방어 레버**다. 피해가 도구 오남용이 아니라 출력 그 자체이기 때문(이루다형: 도구 0개, 혐오발언 출력으로 3주 만에 중단).

**스코프** —
- 주력: **한국어 음운 축**(된소리·연음·발음 보존 변형) — NFKC 불가 × 영어에 부재 = 유일한 해자.
- 대조군: 시각/자소 축(호모글리프·자모 교체 등) — 방어법이 이미 공개된 범용 축이라 "이건 정규화로 죽고 음운만 살아남음"을 대비시키는 용도로만.
- 대상: 입력단 · 순수 대화형 챗봇 · 콘텐츠 분류기 레이어.
- 제외: 타 언어 우회, 멀티모달, 에이전트형(도구호출·파일접근) 위협.

**포지셔닝(톤)** —
1. 세계 최초 발견 아님 — "단일 분류기형 가드레일은 구조적으로 뚫린다"는 국제적으로 확립된 패턴을 **한국어 음운축에서 처음 정량 확인**.
2. 게이트웨이는 완전 해법 아님 — "배포된 단일-분류기 가드레일에 즉시 적용 가능한 진단도구 + 임시 완화책". defense-in-depth의 한 겹.

**산출물 3종** —
1. **정규화/복원 게이트웨이**(최우선) — pip 설치형, 규칙기반 우선 + 모델 cascade fallback.
2. **벤치·평가 하네스** — 회피율 측정, 게이트웨이 필요성의 실측 근거.
3. **난독화 생성 라이브러리** — 강도별 변형 생성기, 독립 재사용 레드팀 도구.

## 2. 계획

**대상 가드레일** — 오픈·독립·결정론적이어야 함(전처리 레이어를 실제로 부착·측정 가능해야 하고, 오픈 가드레일 볼트온이 곧 현실 배포 맥락). 프론티어는 부착·측정·귀속 모두 불가라 대상 부적합.
- 주력: **카나나 Safeguard-8b**(유해 콘텐츠: 혐오·괴롭힘·성·범죄 = **어휘적** 신호) — 음운 난독화가 가장 잘 걸리는 범주.
- 일반성용: Llama Guard / ShieldGemma 중 1종 추가("한 모델 버그" 반박 차단).
- 부차: Safeguard-Prompt(인젝션 = 구조적 신호)는 난독화 영향이 작아 후순위.

**지표** — ER(회피율=가드레일 통과율), ASR(통과 + LLM이 실제 유해출력), FPR(오탐율), Recovery(ER 감소폭)·잔여 ER·복원 충실도(chrF/BERTScore).

**실험 순서**
0. **데이터** — 유해 시드(KOTOX·보유 HF셋), benign 구어체 세트(NSMC·KOLD 무해분).
1. **난독화 생성기** — taxonomy를 가족(음운/시각)으로 분류 + 강도축 파라미터화, `(원문, 난독화문, 가족, 강도)` 페어 저장.
2. **★ Disparity 측정(go/no-go 관문)** — 강도축에 ER·ASR·LLM이해도 3곡선을 그려 ASR '스위트스팟'을 찾는다. **여기서 신호가 죽으면 게이트웨이를 짓지 않는다**(대상 교체/피벗). 지금 6샘플 게이트를 20~30개로 확장하는 게 이 단계.
3. **오탐 베이스라인** — benign 세트로 게이트웨이 없는 FPR 측정.
4. **게이트웨이 구현** — 규칙기반 우선, cascade.
5. **최종 측정** — ER/ASR 회복 + **ΔFPR(≈0 필수)** + 복원 충실도, 가드레일 2종.
6. **시연** — 원문 통과 → 게이트웨이 → 차단, on/off 실시간 비교.

**핵심 원칙**
- 게이트웨이는 정규화만, 판단 안 함 → 범주 무관, 커버리지 상한 = 하위 가드레일의 원문 성능.
- 헤드라인 지표는 "회복한 회피량"이 아니라 **"오탐을 안 올리면서 회복한 회피량"**. benign/FPR이 빠지면 심사에서 찔린다.
- 구현은 규칙기반 우선(추가 비용 near-zero), 모델은 측정된 recall 갭에만 cascade로.
- 복호화(가역)가 아니라 **best-effort 복원**(g2p⁻¹은 lossy). 과약속 금지.

**현재 상태** — 사전조사 완료. 게이트 실험 완료(된소리·쌍자음화 5/6=83% 회피, 강도-회피율 서열 반전 발견). 다음 = 2단계 disparity 재현.

## 3. 조사한 것 (결론만)

**가드레일 방어율 현실** — 프롬프트 인젝션 성공률 50~84%, 적응형 85%+, Azure/Meta Prompt Guard 100% 회피 사례. 단 레이어링 시 73%→8.7%. → "가드레일 무용"이 아니라 **defense-in-depth가 컨센서스**이고, 게이트웨이는 그 한 겹. (가치 상한은 캡됨: "챗봇을 안전하게"가 아니라 "가장 싼 한국어 회피의 비용을 올린다".)

**문자 난독화 방어는 "이미 공개됨"** — NFKC + Unicode TR39 confusables `skeleton()` + zero-width/태그 제거 + retokenization. ※NFKC 단독은 호모글리프(교차 스크립트 confusables)를 **못** 잡음 — TR39 skeleton이 별도로 필요. 반면 **음운 변형은 정상 바이트라 정규화 대상이 없어 미해결** = 우리 축. 근거: Yong et al.(2310.02446), Broken-Token/CPT-Filtering(2510.26847).

**한국어 실제 공격 실태** — LLM 가드레일 대상으로 **문서화된 한국어 공격은 전부 번역 기반(표준 한국어 + 롤플레이/인젝션 구조)**. 된소리/자모/초성 같은 음운·표기 난독화는 **구식 키워드/정규식 욕설필터** 우회로만 문서화돼 있고, LLM 안전 가드레일을 탈옥시킨 공개 사례는 없음.
- → 양날: (+) 우리가 하면 **최초**(신규성↑). (−) 핵심 전제가 6샘플 게이트 외엔 **미검증**(리스크). LLM이 뭉개진 텍스트도 추론하는 성질 때문에 가드레일도 뚫고 이해·차단할 가능성 배제 못 함 → 2단계가 관문인 이유.
- 한국어 = **중자원**(DAMO-NLP 2310.06474), ASR 다국어 평균 수준(비의도 4~10%, 의도 35~80%). **"한국어라 특히 약하다"는 과장 금지** — 저자원 논리는 보조근거, 주근거는 "배포가 받는 입력 분포".

**인접 선행연구 — "국내외에 없음"은 틀림, 완화 필요** —
- **PHISH in MESH(2505.21380)** — 한국어 음운 치환 공격 + g2pK 음소를 분류기에 주입하는 방어. 혐오 BERT F1 56.6→70.9. 우리와 다름(대상=혐오분류기, 방어=재학습형). 하지만 "음운 난독화 처음"은 거짓이 됐고, 동시에 우리 전제를 **부분 방증**.
- **KOTOX(2510.10961)** — 한국어 유해 텍스트 deobfuscation 데이터셋·모델(경음화/연음 many-to-one 모호성 분석). 정렬된 난독화↔원문 페어라 **재사용 가능**.
- 잔여 Gap = "**프롬프트-인젝션/콘텐츠 가드레일 대상 + 무재학습·모델무관 전처리**" 축은 여전히 비어있음.

**구현·ROI** — SLM 유일 아님. **규칙기반**(python-jamo·hgtk·g2pK·soynlp)이면 CPU 문자연산 = 추가 비용 near-zero. 난독화=forward g2p, 방어=g2p⁻¹(lossy: 경음화 ㄱ/ㅋ/ㄲ 삼중, 연음 형태소경계 모호) → 음소키 매칭 + close-enough 복원으로 완화. 기존 한국어 욕설필터가 규칙기반 deobfuscation을 딥러닝 없이 프로덕션에서 이미 수행 → 실현성 입증. **ROI 강하게 우호적**. 초성체·신종·중첩만 모델 fallback.

**확보 자원** — 시드셋(HF) `kimchunsik03/KoreanGuardrail`(스키마·라이선스 검증 전), KOTOX 데이터셋.
