# 초성체 어휘 후보 개발 진단

> 실행일: 2026-08-08
>
> 상태: `PROVISIONAL_DEV_ONLY`

일반 한국어 빈도 사전만으로 초성체를 얼마나 복원할 수 있는지 확인했다. 이 진단은 가드레일 모델을
실행하지 않으며, 후보 생성 coverage와 원문 대비 문자 복원만 측정한다.

## 실행 조건

- 입력: `hf_repo/benchmark.jsonl`의 `chosung` 1,010행, 독립 seed 505개
- 입력 SHA-256: `fbf9f978996c103b8d5625e55936e536610fbceb2a43dc2f53c1271423873b0b`
- 어휘 사전: `wordfreq` 3.1.1 한국어 상위 30,000개 요청
- 실제 인덱싱: 완성형 한글 단어 25,360개
- 최소 초성 증거: span당 3개
- span 후보: 최대 3개
- 문장 후보: 원문 포함 최대 16개
- benchmark 원문은 후보 사전 생성과 순위화에 사용하지 않음

`최선 초성 위치 복원`은 생성된 후보 중 원문의 해당 음절을 가장 많이 맞힌 후보의 비율이다. 실제
gateway는 원문을 알 수 없으므로 이는 배포 성능이 아니라 현재 후보 집합의 oracle 상한에 가깝다.

## 판정

`wordfreq` 빈도순 후보만으로는 초성체 gateway를 활성화하지 않는다.

- 완전 초성체에서 거의 항상 후보가 생기지만 올바른 음절 coverage가 낮다.
- 문장당 후보가 빠르게 상한에 도달해 문맥 없는 조합 탐색이 비효율적이다.
- benign에서도 후보 생성률이 더 높아 단순 OR 판정은 ΔFPR을 높일 위험이 있다.
- 기본 `normalize_korean()`에 연결하면 기존 무손실·clean mutation 0% 경계를 훼손한다.

## 다음 요구사항

1. 공개 benchmark와 분리된 초성 통신체·정상 약어 dev 세트를 먼저 만든다.
2. 일반 빈도순이 아니라 문장 문맥을 사용하는 ranker를 비교한다.
3. 후보 생성기와 가드레일 사이 집계 규칙을 사전등록한다. 단순 OR 외 top-k, score threshold를 포함한다.
4. attack TPR뿐 아니라 초성 통신체 hard-negative ΔFPR을 함께 측정한다.
5. 새로운 locked test를 확보하기 전 결과는 최종 방어 성능으로 사용하지 않는다.

현재 구현한 `ko_chosung.py`는 이 후속 실험을 위한 dependency-free 후보 생성·추적 계층으로 유지한다.
